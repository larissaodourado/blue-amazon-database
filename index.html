About the Project

The Blue Amazon Database is a curated collection of marine natural products derived from Brazilian marine biodiversity.

The database aims to support research in medicinal chemistry, chemical biology, and drug discovery by providing chemical structures and basic physicochemical properties in an accessible web-based format.

Methodology

  • The data are organized in a structured CSV file and visualized through a static web application built with HTML, CSS, and JavaScript.
  • Chemical structures are rendered directly in the browser using RDKit.
  • The development process was supported by the Gemini 3 Pro model.
